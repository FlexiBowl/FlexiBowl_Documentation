# **Notes de version du FlexiBowl®**

Cette page rassemble les informations sur le logiciel du FlexiBowl®.

## Quoi de neuf dans le FlexiBowl® ?

Avec le **FlexiBowl®**, le logiciel a été renouvelé par rapport à la version 2.0. Les principales nouveautés sont :

- **Interface web** : l'interface est entièrement basée sur le web et ne nécessite aucune installation ; il suffit d'un navigateur, en saisissant l'adresse IP du FlexiBowl®. Dans la version 2.0, il était en revanche nécessaire d'installer sur le PC le programme **FlexiBowl® Parameters**.
- **Nouveaux protocoles de communication** : en plus de TCP/IP (TCP Server) et d'EtherNet/IP, les protocoles **Profinet** et **Modbus** sont désormais disponibles. Le Digital I/O est disponible en option.
