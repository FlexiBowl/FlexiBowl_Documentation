# **Accessoires et Options**

Cette page regroupe les variantes, accessoires et options disponibles au catalogue pour les Bulk Feeder vibrants, classés par fonction. Les Bulk Feeder sont disponibles en six modèles de base (1,5 l, 3 l, 5 l, 10 l, 20 l et 40 l) ; la cuve de 1,5 l est en matière plastique, les autres sont en acier INOX.

:::{attention}
Sauf indication contraire, les accessoires et options **ne sont pas disponibles pour le Bulk Feeder de 1,5 l**. Pour les modèles personnalisés, il faut se référer au dossier technique du projet.
:::

(tramoggia-antivibrazione)=
## Antivibratoire

Le Bulk Feeder génère des vibrations pour faire avancer les pièces dans la cuve. S'il est installé sur le plan d'une machine sensible aux vibrations, il faut interposer un matériau isolant et antivibratoire entre les deux surfaces, afin d'éviter que les vibrations ne se transmettent au FlexiBowl®. Des **éléments antivibratoires** et un **kit antivibratoire** sont disponibles, pour les tailles de 3 l à 40 l.

| | |
|---|---|
| **Fonction** | Isolation des vibrations du Bulk Feeder |
| **Tailles** | 3 l · 5 l · 10 l · 20 l · 40 l |
| **Références** | Installation : {doc}`trasporto_installazione` |

(tramoggia-cavi)=
## Câbles du contrôleur

:::{note}
Les câbles de raccordement du FlexiBowl® (alimentation, Ethernet, I/O, rack) sont décrits dans la page {ref}`Câbles de raccordement <cavi>`.
:::

Le contrôleur du Bulk Feeder utilise deux câbles, tous deux disponibles en longueurs de **3 m, 5 m et 10 m**.

(cavo-modbus)=
### Câble Modbus RTU

Câble de communication **RS485 (Modbus RTU)** entre le contrôleur du Bulk Feeder et le FlexiBowl®. Il se raccorde au connecteur **HOPPER** du FlexiBowl® (panneau standard pour les tailles 500 – 1200, rack pour les tailles 200 / 350) et à l'un des deux ports **RS485** du contrôleur ; l'autre port RS485 permet le raccordement en **daisy chain** de plusieurs Bulk Feeder.

| Broches du contrôleur (RS485) | Description |
|---|---|
| 1 | A+ |
| 2 | NC |
| 3 | B- |
| 4 | GND |
| 5 | NC |

Connecteur côté FlexiBowl® : M12, codage A. Brochage et séquence de raccordement : {doc}`controller_cablaggio`.

:::{important}
Dans une configuration à Bulk Feeder unique, le connecteur RS485 non utilisé doit être fermé avec le **bouchon de terminaison** prévu, doté d'une résistance de **120 Ω** entre A+ et B-.
:::

(cavo-input)=
### Câble d'entrée

Câble pour le raccordement du port **Enable Output Port** (4 broches) du contrôleur, utilisé pour la commande du Bulk Feeder depuis un dispositif externe lorsque celui-ci est acheté séparément. Pour activer la sortie du contrôleur, il faut appliquer un **signal PNP** sur ce port. Brochage et séquence de raccordement : {doc}`controller_cablaggio`.

| Broche du contrôleur | Description |
|---|---|
| 1 | +24V |
| 2 | NC |
| 3 | GND |
| 4 | Input |
