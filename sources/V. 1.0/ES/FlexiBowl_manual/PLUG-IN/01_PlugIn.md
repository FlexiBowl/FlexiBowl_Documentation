#  **Plug-In**

Los Plug-ins de comunicación son herramientas de software esenciales, desarrolladas para estandarizar y simplificar la interfaz entre el sistema FlexiBowl® y el entorno de automatización (robots industriales).

:::{important} 
Todos los plug-ins deben solicitarse por correo electrónico a service@arsautomation.com, indicando el modelo de robot y la versión del controlador. 
:::
