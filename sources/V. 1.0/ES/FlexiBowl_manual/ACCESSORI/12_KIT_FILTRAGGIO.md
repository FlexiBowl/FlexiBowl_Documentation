# **Kit externo de filtrado de aire**

Para su alimentación neumática, el FlexiBowl® requiere aire comprimido limpio conforme a la norma **ISO 8573-1:2010 clase 1.3.2**, es decir:

* Las partículas sólidas deben tener un tamaño ≤0,1 μm;

* Punto de rocío a presión ≤-20 °C (ausencia de condensación o escarcha);

* Concentración de aceite (incluidos aerosoles y vapores) ≤0,1 mg/m³.

Si no es posible garantizar este nivel de limpieza del aire, se puede adquirir el kit de filtrado externo, que debe conectarse directamente antes del FlexiBowl®.

:::{note}
El kit dispone de un racor Ø8 tanto en la entrada como en la salida e incluye una reducción para la salida de Ø8 a Ø6 para los FlexiBowl® 200 y 350. Además, se incluye un filtro de repuesto para cada uno de los dos grupos filtrantes.
:::
