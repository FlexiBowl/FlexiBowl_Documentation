# Note di rilascio del FlexiBowl®

Questa pagina raccoglie le informazioni sul software del FlexiBowl®.

## Cosa è nuovo in FlexiBowl®?

Con **FlexiBowl®** il software è stato rinnovato rispetto alla versione 2.0. Le principali novità sono:

- **Interfaccia web**: l'interfaccia è completamente web-based e non richiede alcuna installazione; è sufficiente un browser, digitando l'indirizzo IP del FlexiBowl®. Nella versione 2.0 era invece necessario installare sul PC il programma **FlexiBowl® Parameters**.
- **Nuovi protocolli di comunicazione**: oltre a TCP/IP (TCP Server) ed EtherNet/IP, sono ora disponibili i protocolli **Profinet** e **Modbus**. Il Digital I/O è disponibile come opzione.

