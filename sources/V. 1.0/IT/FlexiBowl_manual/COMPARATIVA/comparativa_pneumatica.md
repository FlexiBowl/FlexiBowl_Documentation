# **Comparativa Pneumatica**

## Componenti del sistema pneumatico

| Componente         | FlexiBowl® 2.0 | FlexiBowl® 3.0 |
|--------------------|----------------|----------------|
| Filtro aria        | ✓ Integrato nel pannello (resistenza fino a 10 Bar) | ✓ Integrato; kit filtrazione esterno opzionale disponibile |
| Elettrovalvole     | ✓ Per Flip, Blow, Svuotamento | ✓ Per Flip, Blow, Svuotamento |
| Regolatore di pressione | ✓ Con connettori dedicati | ✓ Con connettori dedicati |
| Flip               | ✓ | ✓ |
| Svuotamento (QuickEmpty) | Opzionale | Opzionale |
| Blow               | Opzionale | Opzionale |

## Specifiche dell'aria compressa

| Parametro                          | FlexiBowl® 2.0       | FlexiBowl® 3.0                              |
|------------------------------------|----------------------|---------------------------------------------|
| Qualità aria richiesta             | Non specificata nel training | Aria compressa pulita ISO 8573-1:2010, classe 1.3.2 |
| Pressione minima di alimentazione  | Non specificata nel training | 7 Bar                                       |
| Ø tubo alimentazione – FB200       | Non specificato       | Ø 6 mm                                      |
| Ø tubo alimentazione – FB350–1200  | Non specificato       | Ø 8 mm                                      |
| Resistenza massima filtro          | 10 Bar               | —                                           |
| Tensione elettrovalvole            | +24V DC              | +24V DC                                     |

## Schema funzionale (invariato)

In entrambe le versioni, lo schema pneumatico segue la stessa logica funzionale:

**AIR SUPPLY → FILTRO → Elettrovalvole → BLOW / SVUOTAMENTO / (Regolatore di pressione → Elettrovalvola → FLIP)**

## Note al confronto

- Nel FB 3.0 vengono introdotti gli **schemi pneumatici ufficiali** per tutti i modelli (varianti C e CC), incluse le versioni **Clean Room**, dove la modifica riguarda componenti e collegamenti pneumatici specifici.
- Le specifiche ISO 8573-1:2010 classe 1.3.2 e il requisito di 7 Bar sono indicazioni formali nuove nella documentazione FB 3.0; nella documentazione FB 2.0 erano implicite ma non tabulate.
- È disponibile su richiesta un **kit di filtrazione aria esterno** per impianti con qualità dell'aria non garantita.
