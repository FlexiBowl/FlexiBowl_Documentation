# **Layout Best Practice**

## Guidelines for robot placement

:::{tip}
The best way to place the robot relative to the FlexiBowl® is the one that minimizes *pick and place* paths.
:::

### Traditional operation

When the FlexiBowl works in standard mode, the robot's work area should cover the vision area, so that the robot is able to reach and pick all the components identified as pickable.
