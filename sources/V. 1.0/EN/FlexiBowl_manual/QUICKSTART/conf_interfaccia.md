# **Interface Configuration**


:::{note}
If the system in use is **FlexiVision One**, the configuration is managed entirely through its dedicated interface. It is not necessary to use the FlexiBowl® software interface described in this section. Refer to the {ref}`FlexiVision One Manual <flexivision_one>`.
:::

## First start-up

On first start-up of the system, follow the guided procedure below to configure communication and prepare the FlexiBowl® for use.

::::{list-table}
:widths: 10 90
:header-rows: 1

* - Step
  - Operation

* - 1
  - Enter the **IP address** of the FlexiBowl® in the browser's address bar to access the software interface. The default IP address of the FlexiBowl® is `192.168.1.10`.

* - 2
  - The **Home page** opens. Select the desired **language** from the drop-down menu at the top right.

* - 3
  - Open the **Setup** page from the side menu.

* - 4
  - Click **Get IP** to read the device's current network parameters.

* - 5
  - Enter the **new IP address** you want to assign to the FlexiBowl® in the dedicated fields, then click **Set IP**.

* - 6
  - Select the desired **communication type** from the drop-down menu. The default option is **TCP Server**.

    :::{note}
    The **Digital I/O** mode is not included in the standard configuration, but is available as an option that can be purchased separately.
    :::

* - 7
  - Click **Apply** to confirm the communication settings.

* - 8
  - Click **Reboot** to restart the software and make the changes effective.

::::

:::{important}
After the reboot, reconnect to the FlexiBowl® using the new IP address set in step 5.
:::

## Enabling the Backlight (if necessary)

If calibration of the vision system is required, enable the backlight before proceeding:

::::{list-table}
:widths: 10 90
:header-rows: 0

* - 1
  - Open the **Main Command** page from the side menu.

* - 2
  - Select **OPTION** from the **"Chose Visualization Page"** drop-down menu.

* - 3
  - Activate the **Backlight 1** and/or **Backlight 2** toggle as needed.
