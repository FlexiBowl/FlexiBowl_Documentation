# **FlexiBowl® Release Notes**

This page collects information about the FlexiBowl® software.

## What's new in FlexiBowl®?

With **FlexiBowl®** the software has been renewed compared to version 2.0. The main new features are:

- **Web interface**: the interface is completely web-based and requires no installation; a browser is all that is needed, by typing the IP address of the FlexiBowl®. In version 2.0, on the other hand, the **FlexiBowl® Parameters** program had to be installed on the PC.
- **New communication protocols**: in addition to TCP/IP (TCP Server) and EtherNet/IP, the **Profinet** and **Modbus** protocols are now available. Digital I/O is available as an option.
