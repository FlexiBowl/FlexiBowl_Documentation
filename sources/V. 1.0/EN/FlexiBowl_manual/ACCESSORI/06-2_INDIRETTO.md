# **Indirect blows (only for FlexiBowl® 500E)**

Since radial blows are not compatible with the FlexiBowl® 500E, indirect blows can be used to still make it possible to use an air jet as a system for diverting parts from the edge of the rigid disc. These consist of two nozzles that are assembled on the wall of a dedicated flip screen and whose air jet is directed toward the inner face of the disc edge, so as to create a turbulence zone that brings the components toward the center of the FlexiBowl® work area.

:::{figure} ../../../../_shared/media/images/sofind500.PNG
:width: 100%
:align: center
:::

## Recommended applications

They have essentially the same function as radial blows, so they are recommended for the same situations.

## Mounting procedure

:::{warning}
Disconnect the electrical power supply before mounting the blows.
:::

| Step | Operation |
|:----:|-----------|
| 1 | Remove the entire flip screen-barrier assembly by unscrewing the four fixing screws |
| 2 | Replace the screen with the indirect blow assembly |
| 3 | Fix the new indirect blow-flip barrier assembly |

## Adjustment procedure

The blow intensity is adjusted via software by changing the "blow pressure" value. The intensity of each blow can then be set independently using the adjustment needles located under the flip screen support.

:::{figure} ../../../../_shared/media/images/regsof200.PNG
:width: 100%
:align: center
:::

## Checking correct operation

Well-adjusted blows behave as follows:

* The blow upstream of the flip brings the components to about 3/4 of the FlexiBowl® radius starting from the center, where the flip is most effective at turning over and separating the parts;

* The central blow moves the parts away from the disc clamping cap so as to avoid collisions with the gripping tool;

* The blow downstream of the flip moves the components slightly away from the edge of the FlexiBowl®, so as to prevent any collisions with the gripping tool.
