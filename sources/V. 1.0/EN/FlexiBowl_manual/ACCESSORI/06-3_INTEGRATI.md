# **Blows integrated into the flip screen (FlexiBowl® 200-350)**

The flip screens of the FlexiBowl® 200 and 350 are 3D printed. This allows internal channels to be created that end in nozzles specially designed to direct the air jet so as to obtain the same behavior as the equivalent accessories, without the need for additional attachments to be mounted on the FlexiBowl®.

## Recommended applications

They have essentially the same function as the indirect blows and the central blow, so they are recommended for the same situations. On the FlexiBowl® 200 they are the only diverting system available.

## Mounting procedure

The blows integrated into the flip screen are fitted by default on the FlexiBowl® models they are compatible with.

## Adjustment procedure

The blow intensity is adjusted via software by changing the "blow pressure" value. The intensity of each blow can then be set independently using the adjustment needles located under the flip screen support.

## Checking correct operation

Well-adjusted blows behave as follows:

* The blow upstream of the flip brings the components to about 3/4 of the FlexiBowl® radius starting from the center, where the flip is most effective at turning over and separating the parts;

* The central blow moves the parts away from the disc clamping cap so as to avoid collisions with the gripping tool;

* The blow downstream of the flip moves the components slightly away from the edge of the FlexiBowl®, so as to prevent any collisions with the gripping tool.
