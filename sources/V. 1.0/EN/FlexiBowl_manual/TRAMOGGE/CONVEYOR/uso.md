# **Use**

During operation the machine does not require continuous supervision by an operator. The operator's only function is to check that the machine is working correctly and that the work cycle is running regularly.

:::{important}
The machine has no specific start and stop controls. The operating logic must be integrated by the user into the final destination line.
:::

## Preliminary checks

Before starting the machine, carry out the following checks:
- check that the machine has been correctly incorporated into the final destination line;
- make sure the safety devices work correctly and effectively;
- check that there are no unauthorized persons in the hazardous areas;
- check that the space around the machine is free of obstacles and/or clutter;
- check that the machine has been correctly connected to the electrical mains;
- check that the safety functions of the destination line have been correctly integrated into the machine;
- check that the upstream feeding system is correctly positioned and connected to the machine's operating logic;
- check that the downstream discharge system is correctly positioned and connected to the machine's operating logic;
- check that the machine is not in "Maintenance" status.

## Operating procedures

:::{important}
For all information on the use of the machine, refer to the manual of the line in which it is incorporated.
:::
