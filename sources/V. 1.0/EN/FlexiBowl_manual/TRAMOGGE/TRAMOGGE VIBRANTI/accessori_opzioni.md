This page lists the variants, accessories and options available in the price list for the vibratory hoppers. Each price list item has its own section, reachable through a direct link.

(cavo-modbus)=
### Modbus RTU Cable

**RS485 (Modbus RTU)** communication cable between the hopper controller and the FlexiBowl®. It connects to the **HOPPER** connector of the FlexiBowl® (standard panel for sizes 500 – 1200, rack for sizes 200 / 350) and to one of the two **RS485** ports of the controller; the other RS485 port allows **daisy chain** connection between multiple hoppers.

:::{list-table}
:widths: 30 70
:stub-columns: 1

* - FlexiBowl® side connector
  - M12, A-code
* - Controller side connector
  - 5-pin (RS485 port)
* - References
  - Pinout and connection sequence: {doc}`controller_cablaggio`
:::

| Controller pin (RS485) | Description |
|---|---|
| 1 | A+ |
| 2 | NC |
| 3 | B- |
| 4 | GND |
| 5 | NC |

:::{important}
In single-hopper configuration, the unused RS485 connector must be closed with the dedicated **termination cap**, fitted with a **120 Ω** resistor between A+ and B-.
:::

### Input Cable

Cable for connecting the controller **Enable Output Port** (4-pin), used to command the hopper from an external device when the hopper is purchased separately. To enable the controller output, a **PNP signal** must be applied to this port.

:::{list-table}
:widths: 30 70
:stub-columns: 1

* - Controller side connector
  - 4-pin (Enable Output Port)
* - System side connector
  - 
* - References
  - {doc}`controller_cablaggio`
:::

| Controller pin | Description |
|---|---|
| 1 | +24V |
| 2 | NC |
| 3 | GND |
| 4 | Input |
